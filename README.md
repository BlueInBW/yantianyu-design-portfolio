# 闫天御 · 视觉作品集

最初上传的14页作品集网页版，保留原有内容与页序。61个产品、海报及视觉单元在原位置逐件呈现，页面背景跟随当前作品配色。支持重播、一键显示整页、自动播放、目录跳转和高清原图放大，适配手机和电脑，尊重系统减少动态效果设置。

使用 HTML、CSS 和原生 JavaScript，不依赖外部字体、分析服务或第三方运行时。通过 GitHub Pages 发布。

本地预览：`python -m http.server 8176 --bind 127.0.0.1`，在浏览器打开输出的本地网址。

键盘：左右方向键切换展示，空格呈现下一项，Esc 关闭弹窗。点击图片可查看大图。

高清图片和下载PDF均直接复制自原版，未对原作替换、补绘或调色。网页预览采用压缩图，放大时加载8000像素原图。IP形象页面包含AI辅助设计。

页内交互采用原图遮罩与定位显示，所有单元就位后恢复完整原图。重建素材后运行 `node ../scripts/configure_original_interactions.mjs` 生成展示位置。

作品与图片仅用于个人作品展示，未经许可请勿转载。
